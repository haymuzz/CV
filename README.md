# Егор Хаймусов — CV / Portfolio

Адаптивный сайт-резюме для GitHub Pages с оформлением по направлению **B**: тёмный первый экран с крупной типографикой и чёрно-белым портретом, зелёные акценты, светлые разделы, блоки навыков, портфолио и контактов.

Это оригинальная вёрстка, созданная на основе композиционных ориентиров, предоставленных владельцем, без копирования исходного шаблона.

## Разделы

- Главный экран — имя, роль и фотография.
- Обо мне — факты из публичного портфолио.
- Навигационные блоки Skills / Portfolio / Research.
- Навыки — Python, SQL, продуктовая аналитика, ETL и другие.
- Портфолио — шесть проектов со ссылками на их каталоги на GitHub.
- Исследования — три дополнительных репозитория.
- Контакты и форма письма.

**Форма** не использует сервер. После заполнения открывает почтовое приложение через `mailto:` с подготовленным письмом; она не отправляет письмо автоматически.

## Фото

Используется `assets/profile-photo-v2.webp` — фотография, ранее предоставленная владельцем.

## Публикация

GitHub Pages: **Settings → Pages → Deploy from a branch → main / (root)**.

Адрес: https://haymuzz.github.io/CV/

## Сведения

Имя, роль Business Analyst, проекты и навыки основаны на публичных GitHub-репозиториях владельца. Образование, возраст, стаж и другие неподтверждённые данные не добавлены. Контакты и фото будут публичными на опубликованном сайте.
