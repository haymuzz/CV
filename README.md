# Егор Хаймусов — CV / Portfolio

Адаптивный сайт-резюме для GitHub Pages. Оригинальный editorial-дизайн, вдохновлённый современными шаблонами резюме: светлый фон, крупная типографика, портрет, структурированные блоки навыков и проектов.

## Состав
- `index.html` — страница;
- `styles.css` — стили и адаптация к мобильным устройствам;
- `script.js` — мобильная навигация;
- `assets/profile-photo-v2.webp` — изображение владельца, загруженное ранее;
- `.nojekyll` — публикация без обработки Jekyll.

## Публикация
Сайт расположен в корне ветки `main`. Для GitHub Pages: **Settings → Pages → Deploy from a branch → main → /(root)**.

Адрес: https://haymuzz.github.io/CV/

## Сведения
Имя, контакты, технология и названия проектов взяты из уже опубликованного портфолио [haymuzz/MyProjects---DataAnalyst](https://github.com/haymuzz/MyProjects---DataAnalyst) и связанных репозиториев. Неподтверждённые сведения об образовании и опыте не добавлены.

## Редактирование
Для изменения текстов редактируйте `index.html`, цвета и отступы находятся в `styles.css`. Фото оставлено высокого разрешения, но кадрирование адаптируется к экрану.

При публикации сайта фотография, электронная почта и Telegram становятся доступны посетителям.
