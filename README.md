# Егор Хаймусов — сайт-резюме

Одностраничное адаптивное CV для GitHub Pages в строгом монохромном стиле с портретом.

## Содержимое

- `index.html` — страница резюме;
- `styles.css` — адаптивное оформление;
- `script.js` — мобильное меню и год в подвале;
- `assets/profile-photo.jpg` — портрет (уменьшенная версия фотографии, предоставленной владельцем);
- `.nojekyll` — отключение Jekyll.

## Публикация на GitHub Pages

1. Откройте [Settings → Pages](https://github.com/haymuzz/CV/settings/pages).
2. В **Build and deployment** выберите **Deploy from a branch**.
3. Укажите ветку **main** и каталог **/(root)**, затем **Save**.
4. После публикации сайт будет доступен по адресу https://haymuzz.github.io/CV/ .

## Источники информации

Описание, навыки, проекты, PDF-резюме и контакты взяты из уже опубликованного GitHub-портфолио [MyProjects---DataAnalyst](https://github.com/haymuzz/MyProjects---DataAnalyst) и других публичных репозиториев. Неизвестные сведения об образовании или опыте работы не выдуманы. LinkedIn оставлен заполнителем.

## Перед публикацией

Проверьте, готовы ли вы публиковать фото, адрес электронной почты и Telegram: сайт доступен всем посетителям. Адрес и телефон не добавлялись.
